# AE脚本集合器 V1.0 完整测试用例

## 0. 测试范围与统一约定

### 0.1 覆盖范围

- Electron Renderer UI
- 主进程脚本库与本地加密 SQLite
- 内置资源清单、脚本加密和资源完整性校验
- JSX/JSXBIN 导入与 AE 执行桥接
- 会员登录、卡密激活、设备绑定、在线授权和离线授权
- Windows 安装包、Portable 包、跨电脑迁移
- IPC、ASAR、数据库、网络重放和调试攻击

### 0.2 测试环境矩阵

| 维度 | 最低覆盖 |
|---|---|
| Windows | Windows 10 x64、Windows 11 x64、Windows 11 ARM64（如交付） |
| macOS | Intel、Apple Silicon；受支持的最低 macOS 与当前版本 |
| AE | CS6、早期 CC、中期 CC、AE 2022/2024、AE 2026；至少覆盖已运行/未运行 |
| 安装形态 | NSIS 安装包、Portable 绿色版、目录版 `build:dir` |
| 网络 | 正常网络、断网、DNS失败、TLS失败、HTTP 5xx、慢网络 |
| 权限 | 普通用户、受限用户、管理员、macOS Gatekeeper 开启 |
| 数据 | 空脚本库、免费/会员内置脚本、合法/损坏 JSX、JSXBIN、AEX |

### 0.3 测试账号与数据

- `free-user`：无会员权益。
- `member-user`：有效会员，至少包含脚本 `premium-1` 权益。
- `expired-user`：会员已到期。
- `banned-device-user`：设备状态为 `banned`。
- `valid-card`：未兑换、有效卡密。
- `used-card`：已兑换卡密。
- `revoked-card`：已作废卡密。
- 离线 JWS：服务端签名、绑定测试设备公钥、有效期 7 天。
- 测试脚本：正常 JSX、语法错误 JSX、合法 JSXBIN、损坏 JSXBIN、合法/损坏 AEX。

### 0.4 统一结果约定

- “阻断”：不得解密会员脚本、不得发送至 AE、不得改变授权状态。
- “降级”：保留免费内置脚本和外部脚本，会员功能提示联网或授权失败。
- 不将“无法阻止本机管理员读取运行时内存”判为产品缺陷，但必须记录为已知限制。

## 1. UI 功能测试

### UI-001 左右分栏比例与最小窗口

- 测试场景：验证默认左 3、右 7 布局和窗口缩放。
- 前置条件：启动开发版或已安装应用；脚本库至少有 5 个脚本。
- 操作步骤：启动应用；拖动窗口到最小尺寸；放大、缩小、最大化窗口；观察左右面板。
- 预期结果：左侧约占 30%、右侧约占 70%；最小尺寸不重叠、不出现不可操作控件；列表和详情区可滚动。

### UI-002 搜索实时过滤

- 测试场景：按名称、简介和备注搜索。
- 前置条件：脚本名称分别包含 `Ease`、`Camera`，并为一个脚本设置备注 `常用`。
- 操作步骤：点击搜索框；逐字输入关键词；输入中文、英文、大小写混合、前后空格；按 Escape 清空。
- 预期结果：结果实时过滤；搜索不区分大小写并忽略首尾空格；可匹配名称、简介和备注；清空后恢复当前分类列表。

### UI-003 无搜索结果空状态

- 测试场景：关键词没有匹配项。
- 前置条件：脚本库非空。
- 操作步骤：输入不存在的字符串。
- 预期结果：显示“没有找到脚本”；提示更换关键词或切换分类；不显示“正在加载”假状态；详情区不残留上一个脚本的运行按钮。

### UI-004 空脚本库

- 测试场景：首次安装且没有外部脚本。
- 前置条件：清空外部脚本数据，内置清单为空或只提供不可见测试清单。
- 操作步骤：启动应用。
- 预期结果：显示空状态；应用不崩溃；分类数量为 0；仍可打开设置或导入入口。

### UI-005 分类树展开、折叠和选择

- 测试场景：自研脚本、外部脚本、常用脚本树操作。
- 前置条件：三类脚本均存在，至少一个已收藏。
- 操作步骤：点击每个分类箭头；点击分类下的脚本；切换分类后输入搜索词。
- 预期结果：分类正确展开/折叠；数量与可见脚本一致；点击子项选中对应脚本；搜索仅作用于当前分类。

### UI-006 主题切换与持久化

- 测试场景：深色/浅色主题。
- 前置条件：应用正常启动。
- 操作步骤：点击主题切换；关闭应用；重新启动；检查搜索框、弹出菜单、空状态和详情区。
- 预期结果：所有区域颜色完整切换；文字对比度可读；重启后保留上次主题；无闪烁或未定义颜色。

### UI-007 脚本详情展示

- 测试场景：详情字段完整性。
- 前置条件：选中一个内置会员脚本和一个外部脚本。
- 操作步骤：分别点击脚本。
- 预期结果：显示名称、简介、AE 版本、权限状态、教程、运行模式；特殊字符按文本显示，不产生 HTML 注入。

### UI-008 会员脚本按钮状态

- 测试场景：免费、会员已授权、会员未授权三种状态。
- 前置条件：准备三类脚本和对应会员状态。
- 操作步骤：分别选中脚本。
- 预期结果：免费脚本可运行；已授权会员脚本按钮可用；未授权会员脚本按钮置灰并显示开通/联网提示；UI 状态不能绕过主进程校验。

### UI-009 右键菜单收藏/备注/隐藏

- 测试场景：脚本偏好操作。
- 前置条件：脚本库至少有一个外部脚本和一个内置脚本。
- 操作步骤：右键脚本；执行收藏；编辑备注；隐藏脚本；重新打开分类。
- 预期结果：收藏状态即时更新并进入常用脚本；备注持久化；隐藏后从普通列表消失；内置脚本只能隐藏不能删除；取消收藏可恢复。

### UI-010 IPC 错误展示

- 测试场景：主进程返回脚本不存在、权限拒绝、网络失败。
- 前置条件：通过测试桩让 IPC 返回结构化错误。
- 操作步骤：触发运行、刷新会员、加载详情。
- 预期结果：显示用户可理解的错误提示；不显示堆栈、数据库路径、Token、脚本明文或硬件原始值。

## 2. 脚本库管理测试

### LIB-001 内置脚本启动加载

- 测试场景：程序启动加载内置清单和密文。
- 前置条件：资源清单包含免费和会员脚本，清单签名有效。
- 操作步骤：启动应用；查询脚本列表；选中内置脚本。
- 预期结果：元数据正常显示；内置脚本不依赖外部明文文件；用户数据目录没有生成内置脚本原文。

### LIB-002 内置脚本隐藏

- 测试场景：用户隐藏内置脚本。
- 前置条件：至少有一个内置脚本。
- 操作步骤：右键隐藏；重新启动；使用 `includeHidden=false` 查询。
- 预期结果：脚本从普通列表隐藏；资源仍存在于内置清单；取消隐藏后恢复；不存在删除内置脚本 IPC。

### LIB-003 内置脚本删除攻击

- 测试场景：尝试通过数据库、Renderer IPC、文件操作删除内置脚本。
- 前置条件：已安装应用，有内置脚本。
- 操作步骤：删除 SQLite 中对应偏好行；发送伪造 `scripts:delete`；尝试删除 ASAR 资源条目。
- 预期结果：内置脚本下次启动仍从清单加载；未知 IPC 被拒绝；资源篡改触发完整性失败，不进入执行流程。

### LIB-004 外部正常 JSX 导入

- 测试场景：导入 UTF-8 JSX。
- 前置条件：准备包含 `@name`、`@description` 的合法 JSX。
- 操作步骤：通过主进程文件选择器导入；查看列表和详情；重启应用。
- 预期结果：读取名称/简介；复制到受控外部脚本目录；SQLite 保存 SHA-256 和元数据；重启后仍存在。

### LIB-005 JSX 编码兼容

- 测试场景：UTF-8、UTF-8 BOM、UTF-16LE/BE BOM。
- 前置条件：准备四种编码的合法 JSX。
- 操作步骤：逐个导入。
- 预期结果：均能正确识别或给出明确编码错误；中文名称不乱码；不将原始路径写入日志。

### LIB-006 JSXBIN 导入与去重

- 测试场景：导入合法 JSXBIN 和重复文件。
- 前置条件：准备同一 JSXBIN 的两份副本。
- 操作步骤：导入第一份；再导入第二份。
- 预期结果：第一次成功；第二次按 SHA-256 去重，不创建重复记录；不尝试反编译 JSXBIN。

### LIB-007 AEX 文件分类

- 测试场景：导入合法 AEX。
- 前置条件：准备匹配平台架构的 PE AEX；另备 Mach-O 插件作为不兼容样本。
- 操作步骤：导入文件。
- 预期结果：AEX 可作为外部资源记录；运行按钮显示“需安装/重启”或拒绝直接运行；不把 AEX 传给 `$.evalFile`。

### LIB-008 损坏文件过滤

- 测试场景：空文件、超大文件、符号链接、错误扩展名、错误文件头。
- 前置条件：准备对应样本。
- 操作步骤：逐个导入。
- 预期结果：导入被拒绝；不写入 SQLite；不留下半成品文件；错误码明确。

### LIB-009 元数据编辑边界

- 测试场景：编辑外部脚本名称、简介、标签、分类、教程、AE 版本。
- 前置条件：已有外部脚本和内置脚本。
- 操作步骤：编辑合法字段；提交超长字符串、控制字符、非法分类、非数组标签；尝试编辑内置脚本。
- 预期结果：合法修改持久化；非法输入被拒绝；内置不可编辑；脚本文件 SHA-256 不被改变。

### LIB-010 收藏、备注、隐藏和使用次数持久化

- 测试场景：本地偏好数据库。
- 前置条件：外部和内置脚本均存在。
- 操作步骤：设置收藏、备注、隐藏；运行免费脚本两次；重启查询。
- 预期结果：偏好持久化；使用次数增加；最后使用时间更新；隐藏状态不改变脚本本体。

### LIB-011 本地数据库损坏恢复

- 测试场景：SQLite 文件损坏、字段被删除、数据库无法解密。
- 前置条件：备份数据库后制作损坏副本。
- 操作步骤：替换数据库并启动。
- 预期结果：应用不崩溃；进入可恢复/免费模式；提示重新初始化或恢复；不根据损坏字段解锁会员。

## 3. AE 执行脚本测试

### AE-001 AE 未启动（Windows）

- 测试场景：使用 `AfterFX.exe -r` 启动执行。
- 前置条件：目标版本 AE 已安装但未启动；合法 JSX 可运行。
- 操作步骤：点击运行。
- 预期结果：检测到目标安装；启动 AE；桥接脚本调用 `$.evalFile`；收到成功结果；临时目录被清理。

### AE-002 AE 未启动（macOS）

- 测试场景：使用 `open -a` 启动后通过 Apple Events 执行。
- 前置条件：目标版本 AE 已安装、未启动，系统允许自动化权限。
- 操作步骤：点击运行；首次出现自动化授权时允许。
- 预期结果：启动正确 AE 版本；执行一次；返回成功；未授权时提示系统权限，不循环重试。

### AE-003 AE 已启动且桥接可用

- 测试场景：已运行 AE 通过可信 CEP/本地桥接执行。
- 前置条件：桥接已安装并完成版本握手。
- 操作步骤：选择目标脚本并运行。
- 预期结果：脚本只执行一次；任务 ID 匹配；结果回传；并发点击不会重复执行。

### AE-004 Windows AE 已启动但无桥接

- 测试场景：验证不伪造不存在的外部 DoScript API。
- 前置条件：Windows AE 已运行，未配置可信桥接。
- 操作步骤：运行 JSX。
- 预期结果：返回 `AE_RUNNING_BRIDGE_REQUIRED`；不启动第二个 AE；不重复注入脚本。

### AE-005 多 AE 版本共存

- 测试场景：选择指定 AE 版本。
- 前置条件：安装 AE 2022、2024；均可执行。
- 操作步骤：指定 2022 运行；再指定不存在版本；再取消指定运行。
- 预期结果：精确选择 2022；不存在版本返回 `AE_NOT_INSTALLED`，不静默切换；未指定时使用明确的最高版本并返回实际版本。

### AE-006 ExtendScript 成功返回

- 测试场景：脚本正常执行并返回字符串。
- 前置条件：合法 JSX 最后表达式返回值。
- 操作步骤：运行脚本。
- 预期结果：`ok=true`；返回值被限制长度；UI 显示成功；不把完整大对象写入日志。

### AE-007 ExtendScript 语法错误

- 测试场景：JSX 解析失败。
- 前置条件：准备语法错误 JSX。
- 操作步骤：运行。
- 预期结果：返回 `AE_SCRIPT_ERROR`；显示错误信息和可用行号；任务结束；不自动重复运行。

### AE-008 AE 模态对话框/忙碌/渲染中

- 测试场景：AE 被模态窗口或渲染任务阻塞。
- 前置条件：AE 正在渲染或打开阻塞对话框。
- 操作步骤：从应用运行修改型脚本。
- 预期结果：超时后返回 `AE_EXECUTION_TIMEOUT` 或明确忙碌错误；不自动重试；临时文件清理；应用仍可继续使用。

### AE-009 路径和编码

- 测试场景：中文路径、空格、引号、反斜杠和 Unicode 文件名。
- 前置条件：将应用和脚本放入含中文/空格目录。
- 操作步骤：运行脚本。
- 预期结果：桥接路径转义正确；AE 能打开脚本；结果文件可读；无命令注入。

### AE-010 AEX 不走 JSX 执行链

- 测试场景：误点击 AEX 的运行按钮。
- 前置条件：AEX 已导入。
- 操作步骤：尝试运行。
- 预期结果：返回 `AE_SCRIPT_TYPE_UNSUPPORTED`；不调用 `$.evalFile`；提示使用插件安装流程。

## 4. 会员授权测试

### AUTH-001 新设备账号登录

- 测试场景：新设备首次登录并绑定。
- 前置条件：账号有效；设备安全存储为空；网络正常。
- 操作步骤：输入账号密码；完成设备 Challenge；查看会员状态。
- 预期结果：服务端完成设备绑定；设备公钥写入安全存储；客户端收到在线授权/离线 JWS；Renderer 只显示摘要。

### AUTH-002 卡密激活

- 测试场景：新设备使用有效卡密。
- 前置条件：`valid-card` 未兑换；网络正常。
- 操作步骤：提交卡密；重新打开应用；运行会员脚本。
- 预期结果：卡密原文不写日志/SQLite；会员权益生效；设备绑定；会员脚本可运行。

### AUTH-003 卡密异常

- 测试场景：无效、已兑换、已作废、过期卡密。
- 前置条件：准备四类卡密。
- 操作步骤：逐个激活。
- 预期结果：分别返回明确错误；不改变会员权益；不重复写入设备绑定。

### AUTH-004 正常联网校验

- 测试场景：应用启动和会员脚本运行触发在线校验。
- 前置条件：有效会员、网络正常。
- 操作步骤：启动应用；运行会员脚本；手动刷新授权。
- 预期结果：请求使用 HTTPS、时间戳、Nonce、设备签名；服务端授权有效；缓存更新；运行允许。

### AUTH-005 网络断开 1～7 天

- 测试场景：有效离线授权宽限。
- 前置条件：先在线成功校验并缓存合法 JWS；断开网络。
- 操作步骤：模拟离线第 1、3、7 天启动并运行会员脚本。
- 预期结果：本地验签通过；设备绑定一致；会员脚本可用；显示上次在线时间和剩余宽限；免费功能正常。

### AUTH-006 超过 7 天离线

- 测试场景：离线授权过期。
- 前置条件：缓存 `exp` 超过当前时间或离线宽限超过 7 天。
- 操作步骤：离线启动并运行会员脚本。
- 预期结果：会员脚本被拒绝；提示联网校验；免费内置脚本和外部脚本仍可用；不清空用户脚本。

### AUTH-007 会员自然到期

- 测试场景：会员 `expires_at` 已过期。
- 前置条件：服务端会员到期。
- 操作步骤：联网刷新；运行会员脚本。
- 预期结果：返回到期状态；不签发新的离线授权；会员脚本拒绝。

### AUTH-008 设备封禁

- 测试场景：服务端封禁设备。
- 前置条件：设备已激活；服务端将设备标记 `banned`。
- 操作步骤：在线刷新；尝试运行会员脚本；断网后再运行。
- 预期结果：在线时拒绝并撤销会话；离线期间最多受既有宽限约束；不将封禁状态伪装为成功。

### AUTH-009 缓存绑定和设备迁移

- 测试场景：复制授权缓存到另一台电脑。
- 前置条件：电脑 A 有合法缓存；电脑 B 有不同设备密钥。
- 操作步骤：复制缓存文件到 B；启动并运行会员脚本。
- 预期结果：设备公钥摘要不匹配；进入 `device_changed`；会员脚本拒绝；免费功能可用。

### AUTH-010 系统时间回拨

- 测试场景：修改系统时间延长离线授权。
- 前置条件：有效离线缓存；记录最后可信服务器时间。
- 操作步骤：将本地时间调回授权签发前；运行会员脚本。
- 预期结果：检测 `clock_rollback`；拒绝离线会员运行并要求联网；不崩溃。

### AUTH-011 服务端响应篡改

- 测试场景：篡改会员 API 返回的 `isMember`、`entitlements`、`exp`。
- 前置条件：使用测试代理修改响应；无法伪造服务端私钥。
- 操作步骤：进行在线校验。
- 预期结果：JWS 验签失败；不缓存篡改响应；会员脚本拒绝。

### AUTH-012 会员脚本解密顺序

- 测试场景：未授权时验证密文不被解密。
- 前置条件：未登录或会员已过期；启用解密器调用日志。
- 操作步骤：点击运行会员脚本。
- 预期结果：先完成 `canRunScript`；授权失败时解密器和 AE runner 均未被调用。

## 5. 跨电脑迁移安装测试

### MIG-001 新电脑安装免费模式

- 测试场景：无账号、无缓存的新电脑首次安装。
- 前置条件：准备 NSIS 安装包；新电脑无旧用户数据。
- 操作步骤：安装并启动；查看脚本列表；导入外部脚本。
- 预期结果：内置元数据自动加载；免费脚本可用；可导入和运行外部脚本；会员脚本提示登录/激活。

### MIG-002 新电脑登录恢复会员

- 测试场景：用户更换电脑后重新登录。
- 前置条件：账号有效；新电脑生成新设备密钥。
- 操作步骤：登录；按服务端设备上限完成绑定；运行会员脚本。
- 预期结果：旧电脑设备状态不被错误复制；新设备获得独立绑定；授权成功后会员脚本可运行。

### MIG-003 用户数据保留

- 测试场景：覆盖安装/升级不删除外部脚本和偏好。
- 前置条件：旧版本有外部脚本、收藏、备注。
- 操作步骤：安装新版本覆盖；启动并查询。
- 预期结果：外部脚本元数据、收藏、备注保留；数据库迁移成功；授权缓存按协议处理。

### MIG-004 Portable 搬迁

- 测试场景：复制 Portable 到另一目录/电脑。
- 前置条件：Portable 包和用户脚本数据。
- 操作步骤：复制并启动；检查数据目录、会员状态和外部脚本。
- 预期结果：应用本体可启动；数据写入系统用户数据目录而不是 exe 目录；设备密钥不随 Portable 复制获得。

### MIG-005 降级/回滚

- 测试场景：从高版本回到旧版本。
- 前置条件：先使用新版本生成数据库和授权缓存。
- 操作步骤：安装旧版本并启动。
- 预期结果：不破坏原数据；不接受未知数据库迁移；会员授权按最低客户端版本限制处理；必要时进入免费模式。

## 6. 安全攻击测试

### SEC-001 解压 ASAR

- 测试场景：普通用户使用 `asar extract` 解压 `app.asar`。
- 前置条件：已生成安装包和目录版；准备 ASAR 工具。
- 操作步骤：解压；搜索 `.jsx`、`.jsxbin`、内容密钥、会员私钥、Access Token。
- 预期结果：可识别 JS 代码存在（ASAR 不是加密边界），但不出现内置脚本明文、服务端私钥、缓存密钥；只有密文资源和混淆代码。

### SEC-002 篡改 ASAR

- 测试场景：修改主进程 JS、替换资源清单、删除资源。
- 前置条件：复制原始 `app.asar`。
- 操作步骤：修改后启动应用。
- 预期结果：Electron ASAR 完整性校验或资源签名校验失败；应用拒绝加载或进入安全错误；不静默使用篡改资源。

### SEC-003 修改 SQLite 伪造会员

- 测试场景：修改 `isMember`、`expires_at`、`entitlements` 等字段。
- 前置条件：定位本地 SQLite；备份后使用 SQLite 工具修改。
- 操作步骤：启动；查询会员；运行会员脚本。
- 预期结果：SQLite 不作为授权事实；授权缓存/JWS 校验仍失败或状态不变；会员脚本不可解锁。

### SEC-004 删除或替换离线缓存

- 测试场景：删除、截断、替换授权缓存。
- 前置条件：已有合法缓存。
- 操作步骤：分别删除、修改 Base64、替换其他设备缓存。
- 预期结果：进入未认证/缓存篡改/设备变化状态；免费功能可用；不崩溃、不解锁会员。

### SEC-005 API 抓包重放

- 测试场景：重放激活/校验请求。
- 前置条件：通过测试代理捕获请求；保留原始时间戳、Nonce、签名。
- 操作步骤：重复发送原始请求；修改请求体但保留签名；修改时间戳。
- 预期结果：服务端通过 Nonce、时间戳、请求体摘要和设备签名拒绝；客户端不接受伪造权益。

### SEC-006 API HTTPS 降级

- 测试场景：把 API 地址改为 HTTP 或替换证书。
- 前置条件：测试配置尝试使用 HTTP/错误证书。
- 操作步骤：启动授权校验。
- 预期结果：客户端返回 `AUTH_HTTPS_REQUIRED` 或 TLS 错误；不发送凭据和卡密；不使用未签名响应。

### SEC-007 Renderer 伪造会员字段

- 测试场景：在 DevTools/注入脚本中修改 `canRun`、`isMember`、按钮 disabled 属性。
- 前置条件：开发测试包或模拟 Renderer。
- 操作步骤：修改 UI 后点击运行；直接调用暴露的 IPC。
- 预期结果：主进程重新执行会员校验；未授权时拒绝；UI 修改不能改变实际执行权限。

### SEC-008 未授权 IPC Sender

- 测试场景：从第二个 BrowserWindow 或恶意 WebContents 调用 IPC。
- 前置条件：创建测试窗口/导航到不可信页面。
- 操作步骤：调用脚本、会员、导入等通道。
- 预期结果：返回 `FORBIDDEN_SENDER`；不读取文件、不运行脚本、不返回授权信息。

### SEC-009 远程调试与 Node 注入

- 测试场景：使用 `--remote-debugging-port`、`NODE_OPTIONS`、`ELECTRON_RUN_AS_NODE`、inspect 参数。
- 前置条件：生产安装包。
- 操作步骤：附加启动参数并启动；尝试打开 DevTools。
- 预期结果：Fuse 和生产配置阻止这些入口；DevTools 自动关闭或不可用；无法直接取得主进程变量。

### SEC-010 主进程调试器劫持

- 测试场景：使用管理员调试器 Hook `canRunScript`、`verifyGrant` 或 `crypto.verify`。
- 前置条件：管理员权限和调试工具；仅在授权安全测试环境执行。
- 操作步骤：断点修改返回值；尝试强制 `true`；运行会员脚本。
- 预期结果：记录为“本机管理员不可绝对防御”的已知限制；代码签名、混淆和最小 IPC 提高成本；发布说明不得宣称绝对 DRM；服务端审计可发现异常设备行为。

### SEC-011 内置脚本运行时内存提取

- 测试场景：在 AE 执行期间抓取临时文件/进程内存。
- 前置条件：会员脚本可运行；管理员测试机。
- 操作步骤：监控临时目录和进程内存。
- 预期结果：不产生永久明文文件；任务结束清理临时目录；确认“运行时截获无法完全消除”并记录残余风险。

### SEC-012 路径穿越与命令注入

- 测试场景：脚本名称、路径、分类、备注包含 `..`、引号、换行、Shell 元字符。
- 前置条件：可导入/编辑外部脚本。
- 操作步骤：提交恶意文件名和元数据；运行脚本。
- 预期结果：路径限制和参数转义生效；不覆盖应用文件；不执行额外命令；日志脱敏。

### SEC-013 第三方脚本越权

- 测试场景：外部 JSX 尝试读取授权缓存、调用 IPC、访问应用资源。
- 前置条件：准备恶意 JSX；导入但不自动运行。
- 操作步骤：手动运行并观察文件、进程和网络访问。
- 预期结果：应用明确提示第三方代码风险；不向脚本暴露密钥或 IPC；安全产品/权限策略按系统能力限制；不能宣传为完全沙箱。

### SEC-014 依赖与构建供应链

- 测试场景：锁文件篡改、安装脚本异常、构建产物污染。
- 前置条件：CI 构建环境。
- 操作步骤：启用 lockfile 校验；审查 pnpm install 脚本；比较 staging 与源码清单。
- 预期结果：依赖完整性校验失败即停止；只允许批准的构建脚本；staging 不包含测试、文档、密钥和 source map。

## 8. 缺陷等级

| 等级 | 判定 |
|---|---|
| P0 | 未授权可运行会员脚本、服务端私钥/内容密钥泄露、安装包执行任意外部命令、数据大规模破坏 |
| P1 | 设备封禁失效、离线授权超过7天仍可用、ASAR 篡改静默生效、脚本执行重复造成项目损坏 |
| P2 | 单个平台 UI 严重错位、脚本列表/偏好无法持久化、错误信息不完整 |
| P3 | 文案、间距、非关键日志或轻微兼容性问题 |
